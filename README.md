# IP / CHECK

自分の公開IPアドレスをすばやく確認できる、シンプルな日本語Webサイトです。

## 公式サイト

**[IP / CHECK 公式サイト](https://bananeko12345.github.io/ip-check/)**

ブラウザで公式サイトを開き、「IPをチェック」ボタンを押すと、現在の公開IPアドレスを確認できます。

## 使い方

1. [公式サイト](https://bananeko12345.github.io/ip-check/)を開きます。
2. 「IPをチェック」ボタンを押します。
3. 公開IPアドレス、IPv4 / IPv6の種類、取得できた接続情報を確認します。
4. IPアドレスを使いたい場合は「コピー」ボタンを押します。
5. 再確認したい場合は「もう一度スキャン」ボタンを押します。

## 確認できる情報

- 公開IPアドレス
- IPv4 / IPv6の種類
- 国・地域・都市などの位置情報の概要
- タイムゾーン
- ISP / 組織名
- IP情報の取得時刻

位置情報はIPアドレスから推定された概要です。正確な住所を表示するものではありません。

## 主な機能

- スマートフォンとデスクトップに対応したレスポンシブデザイン
- IP取得中のローディング表示
- 通信に失敗した場合のエラー表示と再試行
- ワンクリックでIPアドレスをコピー
- IP情報をデータベースへ保存しない設計
- 外部IP情報サービスに接続できない場合のフォールバック取得

## ローカルで起動する方法

Node.jsがインストールされた環境で、次のコマンドを実行してください。

```bash
git clone https://github.com/bananeko12345/ip-check.git
cd ip-check
npm start
```

ブラウザで次のURLを開きます。

```text
http://localhost:3000
```

## プライバシー

取得したIP情報は画面に表示するためだけに使用し、このサイトのデータベースには保存しません。IP情報の取得時には、外部のIP情報サービスへブラウザから接続します。
